# Как добавить сервис на портал

Портал читает `web/services.json` на каждый запрос. Добавить сервис — значит
дописать туда один объект. **Перезапускать портал не нужно**, страницу править
тоже: плитка, знак, группа и статус появятся сами.

```json
{
  "id": "novyi",
  "name": "Название",
  "group": "МетОптТорг",
  "summary": "Что человек здесь делает — глаголом",
  "port": 8093,
  "auth": "basic",
  "owner": "кто отвечает",
  "hidden": false
}
```

| Поле | Зачем |
|---|---|
| `id` | латиницей, уникальный; по нему подбирается знак сервиса |
| `group` | раздел на странице; новая группа появится сама |
| `summary` | одна строка, **глаголом**: «Сверять…», «Смотреть…», а не «Система учёта» |
| `port` | порт на 192.168.6.157 |
| `auth` | `basic` · `form` · `roles` — влияет только на подпись «как входить» |
| `hidden` | `true` — временно убрать с портала, не удаляя запись |

## Знак нового сервиса

Знаки собраны из треугольного языка фирменной вертушки и лежат в `index.html`,
объект `SIGNS`. Для нового `id` добавьте туда пару путей в двух фирменных тонах
(`#3F5A8A` и `#142248`) на сетке 100×100.

**Главное правило:** силуэт должен отличаться от остальных **при 26 пикселях**,
а не при 150. На мелком кегле детали пропадают — остаётся форма. Сейчас заняты:
двойной шеврон, штабель слоями, коромысло весов, два пика, вложенный треугольник.

Если знак не задан, плитка отрисуется без него — портал не сломается.

## Чего портал НЕ делает

Не хранит пароли сервисов и не входит за пользователя. Плитка — это ссылка:
сервис сам спросит свой логин и пароль. Поэтому обновлять и перезапускать любой
сервис можно независимо, портал об этом знать не обязан.
