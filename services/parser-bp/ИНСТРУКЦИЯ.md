# Парсер БП — краткая инструкция

Программа проверяет, совпадает ли количество месяцев вывоза в блоке
«Расчет процентов» двумя способами: **по строкам** (сколько строк «Привлеченный
капитал» имеют порядковый номер месяца) и **по ячейке** («Кол-во месяцев вывоза»).

## Установка — один раз

1. Скопировать папку с программой **на локальный диск**, например в `C:\ПарсерБП`
   (из сетевой папки запускать нельзя).
2. Установить Python с https://www.python.org/downloads/ — версию **3.11 – 3.14**.
   При установке обязательно поставить галочку **«Add Python to PATH»**.

Интернет не нужен: все библиотеки лежат в папке `packages`.

## Работа

1. Двойной щелчок по **`ЗАПУСТИТЬ.bat`**.
   Первый запуск — 1–3 минуты (ставятся библиотеки), дальше 5–10 секунд.
   Откроется вкладка в браузере.
2. Выбрать, откуда брать файлы:
   * **Ссылка Битрикс24** — вставить публичную ссылку «Поделиться» на папку Диска;
   * **Папка** — кнопка **«📂 Выбрать папку…»** или путь вручную (можно сетевой `\\сервер\папка`);
   * **Загрузить файлы** — выбрать книги в браузере.
3. Нажать **«▶️ Запустить проверку»**.
4. Посмотреть таблицу и нажать **«⬇️ Скачать отчёт в Excel»**.

Закрыть программу — закрыть чёрное окно консоли.

## Как читать результат

| Цвет | Значение |
|---|---|
| 🟢 зелёный | оба способа дали одно число — всё в порядке |
| 🔴 красный | числа разошлись; в столбце «Расхождение» написано, где и на сколько |
| ⬜ серый | блок пустой: шаблон скопировали, но расчёт не вели. Это не ошибка |
| 🟡 жёлтый | блок найден, но одно из значений прочитать не удалось — проверить лист вручную |

Пример расхождения:
`по строкам 2, по ячейке 3 (разница -1); строки блока: 16, 17`
— значит на листе заполнено 2 месяца, а в ячейке «Кол-во месяцев вывоза» стоит 3.

Столбцы «Файл», «Лист», «Ячейка блока» показывают, где именно смотреть.
В скачанном Excel есть ещё листы **«Сводка»** и **«Пропущенные файлы»**.

## Важно

* Программа **только читает** файлы и ничего в них не меняет.
* Файлы, открытые кем-то в Excel, читаются нормально.
* Старый формат `.xls` не читается — такие файлы попадут в «Пропущенные»,
  их нужно пересохранить как `.xlsx`.
* Просматриваются все листы книги, включая скрытые.

## Если что-то не работает

**Если окно мелькнуло и сразу закрылось** — запустите **`ДИАГНОСТИКА.bat`**.
Он соберёт сведения о системе, откроет файл `диагностика.txt` в Блокноте
и не закроется сам. Этот файл нужно отправить разработчику.

| Сообщение | Что делать |
|---|---|
| «Python не найден» | не поставлена галочка «Add Python to PATH» — переустановить Python. Если Python точно стоит: «Параметры» → «Приложения» → «Псевдонимы выполнения приложения» → выключить `python.exe` и `python3.exe` |
| «Пакеты не подошли к вашей версии Python» | поставить Python 3.11–3.14 или сообщить свою версию разработчику |
| «Не удалось создать окружение .venv» | папка запущена из сети — скопировать на локальный диск |
| «Папка не найдена или недоступна» | проверить, подключён ли сетевой диск и есть ли права на чтение |
