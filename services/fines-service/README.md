# Отчет по штрафам

Веб-сервис для ведения месячных отчетов по административным штрафам автопарка.

## Что умеет

- **Загрузка постановлений PDF** (ГИБДД, МУГАДН) — все поля отчета заполняются автоматически:
  дата, номер постановления, компания, автомобиль, гос. номер, статья КоАП, нарушение, сумма.
- **Документы ФССП** (возбуждение ИП, арест, снятие ареста и т.д.) — автоматически
  привязываются к штрафу по номеру постановления. Если штраф еще не загружен, документ
  попадает в раздел «ФССП без привязки» и привяжется сам, как только штраф появится.
- **Месячные периоды**: месяц открыт → штрафы копятся → «Закрыть месяц» → открывается
  следующий. Архив прошлых месяцев со статистикой доступен всегда.
- **Экспорт** отчета за любой месяц в **Excel** (формат как в образце) и **Word**.
- **Вход по паролю**, оригиналы PDF хранятся и открываются из карточки штрафа.
- Защита от дублей: повторная загрузка того же постановления не создаст вторую строку.

## Запуск локально

```bash
cd fines-service
python3 -m venv .venv && ./.venv/bin/pip install -r requirements.txt
APP_PASSWORD=мой_пароль ./.venv/bin/python app.py
# открыть http://localhost:8077
```

Разовый импорт всех PDF из папки:

```bash
./.venv/bin/python import_folder.py /путь/к/папке/с/pdf
```

## Развертывание на сервере (Docker, рекомендуется)

На сервере уже может работать другой проект — сервис слушает только `127.0.0.1:8077`
и выводится наружу через nginx на отдельном домене или пути.

```bash
# скопировать папку fines-service на сервер, затем:
cd fines-service
APP_PASSWORD='придумайте_надежный_пароль' docker compose up -d --build
```

Данные (база + загруженные PDF) лежат в `./data` — этой папки достаточно для бэкапа.

### nginx: отдельный поддомен (рекомендуется)

```nginx
server {
    listen 80;
    server_name shtrafy.example.com;

    client_max_body_size 50m;   # загрузка PDF

    location / {
        proxy_pass http://127.0.0.1:8077;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

После этого: `certbot --nginx -d shtrafy.example.com` для HTTPS.

## Развертывание без Docker (systemd)

```bash
cd /opt/fines-service
python3 -m venv .venv && ./.venv/bin/pip install -r requirements.txt
apt install poppler-utils   # pdftotext, ускоряет парсинг (не обязательно)
```

`/etc/systemd/system/fines.service`:

```ini
[Unit]
Description=Fines report service
After=network.target

[Service]
WorkingDirectory=/opt/fines-service
Environment=APP_PASSWORD=придумайте_надежный_пароль
ExecStart=/opt/fines-service/.venv/bin/uvicorn app:app --host 127.0.0.1 --port 8077
Restart=always

[Install]
WantedBy=multi-user.target
```

```bash
systemctl enable --now fines
```

## Настройки (переменные окружения)

| Переменная     | Назначение                          | По умолчанию |
|----------------|-------------------------------------|--------------|
| `APP_PASSWORD` | Пароль входа                        | `shtraf2026` — **обязательно смените** |
| `PORT`         | Порт сервиса                        | `8077`       |
| `DATA_DIR`     | Папка данных (БД + PDF)             | `./data`     |
| `SECRET_KEY`   | Ключ подписи сессий                 | генерируется автоматически |

## Как пользоваться

1. Пришел штраф → перетащите PDF на главную страницу (можно сразу несколько).
2. Пришло постановление ФССП → загрузите так же, оно само привяжется к штрафу.
3. Оплатили штраф → кнопка «✓ оплачен» в строке таблицы.
4. Кончился месяц → «Закрыть месяц»: период уходит в архив, открывается новый.
5. Нужен отчет → кнопки «Excel» / «Word» на странице любого месяца.
