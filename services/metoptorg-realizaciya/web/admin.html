Источники данных: напрямую из SQL

Вместо ручной выгрузки файлов сервис может забирать таблицы из базы, куда 1С складывает данные экстрактором. Это снимает две болячки: справочники перестают отставать от движений, а остатки и обороты приходят на одну дату. У каждого входа — своя таблица, берётся только она. Что не включено, по-прежнему читается из файла.

Пересобрать отчёт

Данные забираются из SQL, затем полный прогон: расчёт → дашборд → Excel → контрольные примеры → проверка выгрузки в 1С. Выгрузка движений идёт около 20 минут, весь прогон — примерно полчаса. Каждую ночь в 4:00 это происходит само (в час ночи обновляется «Extractor», три часа запаса). Пока идёт пересборка, пользователи видят предыдущую готовую версию — недособранный отчёт наружу не попадает.
