1 · Источник «из экстрактора» — напрямую из SQL

Сервис может забирать таблицы из базы «Extractor», куда 1С складывает данные. Движения (обороты) и справочники берутся из SQL; фактические остатки грузятся Excel-файлом (блок ниже). У каждого входа — своя таблица, берётся только она. Что не включено — читается из файла в data/. Пароль хранится только в окружении службы (METOPTORG_SQL_PASSWORD в /etc/metoptorg-ostatki.env), в браузере/настройках/git его нет.
Модуль SQL недоступен на сервере (нет python-tds).

2 · Фактические остатки — Excel-файл локально

Файл «Остатки на складах ДД.ММ.ГГ.xlsx». Дата отчёта берётся из имени файла (минус 1 день). Можно также догрузить любую выгрузку 1С (СебестоимостьТоваровОбороты_*.csv, Номенклатура_*.csv, СерииНоменклатуры_*.csv, Склады_*.csv), если не берёте её из SQL.

3 · Пересборка

Тянет включённые SQL-источники и запускает расчёт (stock_report → make_dash → make_excel). Идёт фоново; пока считается, дашборд остаётся доступен.
